# PVP RifleGirl 与 Demo 枪械实施记录

日期：2026-09-26。对应用户已确认的规格见 [PvpRifleGirlMigrationPlan.md](PvpRifleGirlMigrationPlan.md)。本文记录实际实现与验证边界，不把源码检查或本地测试等同于雨云上线。

## 已实现的功能

- 大厅「角色」「服装」进入同一个外观与配装页面。可选择 RifleGirl 三套完整服装、五个面部预设、四个发色、衣装配色、帽子和相容配件。运动装使用原有配色并关闭不相容配件。
- 大厅可选择突击步枪或狙击枪作为主武器，手枪固定为副武器。主武器支持原 Demo 六种瞄具，手枪支持原有铁瞄和红点 3。配置只有在云端保存成功后才作为入场档案。
- 用户名密码注册、登录、退出与云端档案；服务端提供持久化、冲突检查和一次性入场票据。大厅、出生、重生使用服务器批准的同一份角色与配装快照。
- 每位 PVP 玩家只有一个 RifleGirl 全身 Animator 和骨架。本地镜头隐藏头部/头发的直接显示，保留影子和命中区域；双手、服装、远端身体来自同一角色。
- 迁入 Test-FPS Demo 的突击步枪、手枪、狙击枪模型、瞄具、机械动画、声音、枪口与命中特效，未迁入霰弹枪或 Mirror 网络系统。
- 根据 Demo 实际脚本对齐射速、弹药、换弹、切枪、弹速、散布、距离伤害、后坐、开镜、呼吸摆动、移动与冲刺反馈。射击、弹药、换弹完成、伤害与比分由现有 NGO 专服结算。
- PVP 对局增加退出入口，主动退出或断线后返回大厅并保留账号状态。发现协议标识用于拒绝未升级的旧专服。

## 实际适配工作

Demo 的枪械手臂动画不能直接绑定 RifleGirl。生成器仅提取枪体机械部件和动作，以同一 Humanoid 身体的双手 IK 驱动持枪和换弹。没有附加第二套手臂或人物皮肤。

生成器修复了原导入的 Avatar 引用，并为大厅建立独立待机姿态。身体保持原骨架和比例。远端与大厅使用完整原网格；本地第一人称在同一身体 Renderer 上使用私有网格，只隐藏 354 个主要由 Head 骨骼驱动的三角面，防止相机内的头部表面遮挡视野。离开第一人称会还原源网格，实例销毁时释放私有网格。

编辑器同一帧内反复截图曾出现腿鞋错位；对照原网格 CPU 烘焙与实际运行确认是截图缓存假象，已修正截图工具，没有裁剪脚部网格。双手旋转由原枪械掌面与 RifleGirl Humanoid IK 骨轴计算转换，避免直接复制旋转导致反向掌心。

机瞄位置依据原枪械 ADS 轴与实际枪体几何校准。各瞄具按镜壳长度保留眼距，红点 2 的镜片使用独立透明材质，细小红点使用独立放大材质副本；参考项目和原材质未改。狙击枪原始模型没有独立照门，保留其原来的裸枪瞄准方式。8 倍镜使用 15° 视野与原镜片、分划材质；没有额外叠加第二套手臂摄像机。

全身第一人称共用世界相机，不能直接照搬 Demo 独立手臂相机的近景遮挡。开镜时按当前镜壳的真实姿态限制向后的平移；狙击裸枪则使用实际机匣上沿后缘顶点。它们在瞄准轴方向保持至少为近裁剪面加 1 厘米的距离，保留角度后坐、相机抖动与枪械数值。没有把整个枪托边界纳入限制或改变原枪的尺寸。

## 当前边界

- 雨云环境由用户确认是 Windows Server 2022、无域名、通过远程桌面管理。当前工具没有该服务器的远程管理连接，因此尚未完成实际公网部署、HTTPS 证书签发或跨电脑公网验收。
- 项目现有 Collections 1.2.4 不满足已安装 Magica Cloth 2 的程序集条件。生成角色保留服装/头发网格和骨骼动画，目前没有动态布料/头发模拟；未直接升级全项目依赖。
- 枪械参数和驱动逻辑已迁移，但“手感完全一致”需要对照实机操作判断；骨骼比例和全身第一人称与 Demo 原专用手臂存在客观差异。
- 本轮优先改造 PVP，PVE 继续使用既有流程。
